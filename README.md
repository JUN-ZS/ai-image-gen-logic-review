# AI 圖像生成邏輯檢討（Gemini 對話存檔）

Google Gemini 對話頁面完整存檔，主題為 **AI 圖像生成邏輯／三層隔離自審制度／視覺編譯**，內容與 EFV 圖像管線討論相關（提及 EFV、prompt、SET、v6/v7）。

## 來源

- 存檔自：`https://gemini.google.com/app/08cf6c8f9120c9b8`
- 瀏覽器「另存網頁」HTML + `_files` 資源目錄
- 上傳日期：2026-10-20（Asia/Hong_Kong）

## 目錄結構

```
docs/
  AI 圖像生成邏輯檢討 - Google Gemini.html   # 主頁面（需與 _files 同層）
  AI 圖像生成邏輯檢討 - Google Gemini_files/  # 頁面資源（JS/CSS/圖片等）
```

以瀏覽器開啟 `docs/` 下的 HTML 即可離線瀏覽（相對路徑指向同層 `_files`）。

## 隱私處理

公開前已對存檔內的 **Google 帳號信箱、顯示名稱、頁面內長 session token** 做脫敏（`[REDACTED_*]`）。Google 前端公開用的 Firebase `AIza*` client key 為 Gemini 頁面內建設定，未改動。

## 與其他 repo 的關係

- 非龍珠版內容；與 `efv-infinity-v6.4` / `efv-gumen-rock-v7.0` 同屬 EFV 圖像生成討論脈絡，但本 repo 僅為對話存檔，不含管線程式碼。
