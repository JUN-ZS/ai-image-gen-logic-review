# Decision record: CYLINDER_CROSS dense collision atlas

- Decision date: 2026-10-21
- Recorded against branch: `feat/original-sin-bubble-break-engine`

- Record type: workflow change / image-sampling strategy

## Why this change

The original matrix path produces 48 separate H2 images and is suitable for strict per-variant audit, but it is expensive and slow for discovery. The next experiment should instead ask an image-generation model for **one extremely dense image containing many independent CYLINDER_CROSS hammer-pair collisions**. The user will scan/crop this image later and keep only local examples that visibly satisfy the contact contract.

This is a sampling atlas, not a replacement for audited single-image evidence.

## Immutable geometry contract

1. Each interaction is a collision between two distinct plus-shaped cross hammers.
2. Each cross hammer has one straight horizontal crossbar, one straight vertical arm and one long straight handle fixed at the exact center joint.
3. The opposite horizontal ends terminate in short solid cylinders.
4. For every intended valid interaction, the **only allowed first-contact surfaces are the two outer flat circular end caps**, meeting flat face-to-flat face. The cap planes coincide and their normals oppose along the local collision axis.
5. Curved cylindrical barrel walls, crossbar sides, vertical cross arms, corners and handles must not touch first.
6. The hammer head and handle remain one rigid body: no bending, kinking, twisting, telescoping, detaching, or independent head/handle rotation.
7. The contact instances should vary in camera angle, collision-axis direction, perspective, handle roll and spacing, while preserving the same cap-to-cap contact rule.
8. Instances must remain visually separable enough to crop. Dense means tightly packed, not merged silhouettes: leave a small visual moat/negative-space boundary around each pair; do not connect handles or accidentally create three-way collisions between neighboring instances.

## Output contract for the new branch

- Main output: one prompt text file for a single 16:9 dense collision-atlas image.
- Supporting record: a deterministic layout manifest listing the intended interaction IDs, view/axis/pose balance, and crop-review expectations.
- A concise generator handoff document that tells the image model to return one raster image, not 48 files, not a collage made of framed panels, and not an SVG.
- Explicit status: image generation and pixel audit remain `NOT_RUN` until an actual generated image is returned and scanned.
- Keep the strict 48-image H2 matrix script and its audit path unchanged as the evidence-grade alternative. Do not silently claim the dense atlas can pass the 48-variant gate.
- The generated dense atlas may contain visually incorrect samples. The user will scan/crop out correct local collisions; every kept crop must be separately checked against the end-cap and rigid-body contract before being promoted as evidence.

## Intended dense-image composition

Use a single seamless image field with many small, complete two-hammer collision instances, extremely dense but individually traceable. Avoid labeled cells, visible panel borders, arrows, text and graphic dividers. Place each pair in its own local pocket of negative space so neighboring tools cannot merge. Vary horizontal, vertical, rising diagonal and depth-axis collisions; vary grazing, profile, three-quarter, overhead, low/high and macro-like views; vary the handle-roll relations. In every intended instance, show the outer circular cap-to-cap seam clearly enough that a later crop can decide whether it is correct.

## Gate terminology

- `ATLAS_PROMPT_READY`: prompt and layout manifest successfully compiled.
- `IMAGE_REALIZATION_NOT_RUN`: no actual image has been generated by repository code.
- `CROP_CANDIDATES_UNREVIEWED`: candidate crops have not yet been assessed.
- `PIXEL_AUDIT_NOT_RUN`: no candidate is accepted until the actual pixels are inspected.
- The original matrix gate remains `BLOCKED_UNTIL_CYLINDER_CROSS_CONTACT_MATRIX_APPROVED` and is not satisfied by this atlas.
