# EFV Song-Semantic Expansion — Original Sin / Wushuang Bubble-Break

This extension explicitly connects the image-story compiler to the two song repositories:

- JUN-ZS/efv-infinity-v6.4: 《永不退電的一朵花》 — borrow the semantic transformation from external power loss to an internal pulse that survives, including severed copper, nameless light marks, amber pulse, empty socket and underground neon root.
- JUN-ZS/efv-gumen-rock-v7.0: 《古門未啟・聽我（未熄之靈）》 — borrow the dramatic spaces and evidence logic of the unopened bronze gate, reverse-rising well mist, copper mirror, uncounted lives, blue-green lamp, ash lines, hidden sound crystal and an optional threshold.
- JUN-ZS/ai-image-gen-logic-review: build upon the existing Original Sin / Wushuang story engine, its 20 causal kernels, material-compatible shell/fracture pairs, 4-frame H0/H1/H2/H3 story, 9-cell QCTH-F storyboard, and prompt-contract audit.

**Song borrowing rule:** these are semantic visual motifs, not pasted lyrics. The first song supplies the intra-story alpha: the inner pulse persists after the containment system loses power. The second supplies the witness / threshold logic and the cross-story beta: a gate or mirror reveals who was omitted from the official account. The extreme-visual axis changes scale-feel, light, optics and framing only; it may not rewrite physics.

## The formula

~~~
ORIGINAL_SIN
 × FLOWER_ALPHA (11 motifs: unpowered pulse persists)
 × GUMEN_WITNESS (12 motifs: gate / well / mirror / uncounted lives)
 × VISUAL_EXTREMITY (20 treatments)
 × MATERIAL_COMPATIBLE_SHELL_FRACTURE
 × ENVIRONMENT × SCALE × WEAPON_FINISH × CAMERA × PALETTE × AFTERGLOW
 → H0 intact / H1 expose mechanism / H2 one exact first contact / H3 shell broken + people unharmed
 → per-frame formula PROMPT + alpha/beta + audit manifest
~~~

The added semantic layers alone define 11 × 12 × 20 = **2,640 flower/gate/extremity combinations**. These multiply the existing compatible story space; they do not replace it. The sampler balances the 20 original-cause kernels and visits every flower × gate pair in each complete 132-record motif cycle. Seeds are deterministic.

## Four hard narrative states

- **H0 — intact:** one closed shell, no pre-existing cracks; the designated striking face remains visibly separated from the exact six-o'clock contact point P. The song motifs appear only as faint clues.
- **H1 — reveal:** the gate/mirror/well motif exposes the rule and human cost. The shell stays intact and the hammer stays separated; no early contact or cracks.
- **H2 — contact:** one and only one designated thick terminal striking face makes first contact at P. Cracks begin only after contact and propagate outward from P. Song motifs are visual metaphors, never a second strike source; the contact face remains readable.
- **H3 — release:** the shell's existing compatible fracture style is resolved; fragments move away from residents. The inner pulse remains lit without external power, while the gate becomes an optional route. Every resident remains alive and uninjured, and the protagonist does not force forgiveness or a particular future.

The current coordinate contract in the base engine remains authoritative. This extension does **not** overwrite C, P, strike-normal, camera lock, weapon topology, or shell/fracture compatibility. Do not confuse the separate planted-hammer-on-bubble study with this H0–H3 terminal-face impact sequence.

## Windows CMD — export a very large prompt library

~~~
python bubble_break\song_motif_expansion.py --count 10000 --seed 20261021 --mode dual --weapon-topology RADIAL --format jsonl --out out\efv_song_story_10000.jsonl
python -m unittest discover -s bubble_break -p "test_*.py"
~~~

The dual mode emits separate heroine and abstract prompt variants per story record. They are separate fields; do not combine them into one image prompt. Use heroine or abstract for a single branch. Supported weapon paths remain RADIAL, T, and CROSS; keep the chosen topology consistent with downstream frame_pipeline.py and realize_batch.py.

For a first review batch:

~~~
python bubble_break\song_motif_expansion.py --count 132 --seed 20261021 --mode heroine --weapon-topology RADIAL --format md --out out\first_132_song_pairs.md
~~~

Output formats: JSONL (recommended for volume), CSV, JSON (limited to 5,000), and Markdown (limited to 2,000). Each record stores stable story/motif IDs, both semantic source layers, the visual-extremity profile, all four frame prompts, nine-cell storyboard annotations, and text-audit status.

## Audit boundary

PROMPT_CONTRACT_PASS checks that the generated text preserves the base prompt contract. It is **not** evidence that a model rendered the correct pixels. Every output records image_realization=NOT_RUN and pixel_audit_status=NOT_RUN. A genuine pixel audit still requires the actual H0/H1/H2/H3 raster files and image-level review. No images are generated by this script.
