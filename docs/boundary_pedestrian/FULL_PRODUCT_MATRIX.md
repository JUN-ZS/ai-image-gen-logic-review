# 《邊界行人》高多樣性四軸交叉乘積

> **不是同一故事複製八張，而是：打法鎖住，其餘全開。**  
> 每一次 TRY 鎖住該組合的物件幾何、指定接觸面、接觸點與因果狀態；姿勢、鏡頭、人物、場景、道具、故事隱喻可以大幅變化。每個系列固定自己的風格、世界和主角，跨系列才切換世界／美術。

## 四軸及其內部因子

1. **G — IMAGE 物件幾何／接觸**：單 T 槌 H0/H1/H2/H3、雙 T 槌端面、厚十字槌圓形端蓋、90° 線形棒 POS/NEG、側柄種植圓柱、外端接柄種植圓柱、多向扁平面圓頭。這個維度鎖住本次打法；不准用鏡頭或美術偷換接觸面。
2. **C — IMAGE 鏡頭／動作／美術／姿勢**：T 槌 192 軸／相機／蓄力組合、雙 T／厚十字各 48 個接觸矩陣、十種獨立 WASH 構圖、S01 寫實電影／S02 可愛 INS 粉彩／S03 超現實隱喻，以及獨立的四姿勢乘積。
3. **V — VIDEO 時間軸／閉環**：V-01 十秒單場景、V-02 五個獨立關鍵幀、V-03 固定錨點 planted-cylinder、V-04 母圖 Image-to-Video、V-05 雙 T、V-06 厚十字、V-07 線形棒正反控制、V-08 多面圓頭、V-09 六幕／24 卡或 52 鏡頭 MV。
4. **N — 敘事 IMAGE／VIDEO 系列**：18 個固定風格、世界及主角的系列。每個系列內六幕保持角色和畫風連續；跨系列可以換人物、服裝、城市、道具、情緒、故事隱喻與場景。

## 四種獨立動作姿勢

- **P01｜落地蓄力／校準站姿**：飛行打擊物件採寬站姿、前膝屈曲、沿指定軸線蓄力；種植圓柱則是固定錨點旁的校準站姿。
- **P02｜躍起／伸展**：飛行物件可在躍起瞬間定格，但剛體與接觸狀態不變；種植圓柱主角可跨上台階伸手，錨點 P 不移動。
- **P03｜低蹲／跪姿**：低重心、扭身準備或檢查接縫；種植圓柱仍固定，人物跪近接縫檢查。
- **P04｜反向扭身／長距伸展**：表現身體動量與反向平衡；工具仍按聲明作為一個剛體移動，種植圓柱絕不被拔起或改變柄接點。

姿勢是交叉乘積中的獨立因子，不再只靠 Prompt 內一句「動作有變化」。鏡頭、姿勢、風格、世界和角色會在不同 TRY 之間改變；同一個 TRY 的物理接觸契約不變。

## H2 中幀先修正，再派生前後幀：同機位、同槌形、只推進時間

V-02 只配對 **T 槌 H2** 的產品列。它不會把 H0、H1 或 H3 當成獨立中幀再各自亂生五張圖。

固定生成順序：

1. **MID_H2（先做）**：以候選 H2 中幀作 image-edit 母圖，只修正錯誤的 T 槌／接觸幾何。要求單一剛性 T 槌、橫槌頭與柄的 90° 中點接合、指定端面在 P 首先接觸、零縫隙、無穿插；原機位、裁切、透視、背景、角色、握法與光線鎖死。通過人眼幾何檢查後，保存此中幀的 SHA-256 與 HUMAN_ACCEPTED 收據。
2. **PRE_H1（由中幀倒推）**：必須把同一份已驗收 MID_H2 raster 當唯一母圖，不能獨立 text-to-image。只沿已定義的碰撞軸把同一把槌和握柄手部倒退極小距離，留下明確正間隙；不能換機位、裁切、槌頭比例、柄長、場景或人物。
3. **POST_H3（由同一中幀推進）**：同樣以被驗收的 MID_H2 作母圖，只沿原碰撞軸作小幅跟進；裂縫從原接觸點 P 延展，不能新增撞擊點、穿球、改槌形或改機位。

如果 MID_H2 沒有 SHA 相符的人類幾何驗收收據，PRE 和 POST 的狀態就是 BLOCKED_UNTIL_MID_H2_ACCEPTED。單純有 Prompt 不會自動解鎖派生，也不會把「已編譯」當作「已生成／已通過」。

### 前後幀字牌：同一組字，兩種藝術處理

- PRE：before，冷玻璃／冰晶邊光，較薄的青色刻線浮雕。
- MID：middle，中性銀金屬與穩定的中心字牌。
- POST：after，暖熔金／琥珀箔、較深的 3D 擠出和火星高光。
- 合成 VIDEO：video-lock，整段影片固定一套中性字牌外觀；文字內容、LOOP／TRY、方法名稱和 Prompt ID 不變。

每一幀的 poster renderer 記錄同一 text_content_sha256。前後幀可以改字的材質、顏色、厚度和光影，但不得改任何字或編號；ASS 影片層採固定樣式，不會在連續影片中閃爍切換字體風格。

執行 triad 提示詞編譯器：

~~~bash
python bubble_break/boundary_pedestrian_frame_triad.py \
  --package examples/boundary_pedestrian_frame_triad.example.json \
  --mid-image path/to/candidate_or_corrected_H2.png \
  --review-receipt path/to/H2_human_review.json \
  --outdir out/boundary_pedestrian/frame_triad
~~~

review receipt 需綁定同一份 image_sha256、review_status HUMAN_ACCEPTED，並把必要項目（正確 T 拓撲、指定端面在 P 首次接觸、零間隙、無穿插、相機／裁切／槌形／背景鎖定）逐項核為 true。收據 SHA 不符或漏一個檢查，前後幀仍保持 BLOCKED。此工具只輸出可追溯 Prompt，不呼叫影像服務。

## 每張作品的藝術字：佔畫面三分之一、浮雕 3D 海報

每個乘積組合都帶有 art_label_spec，列出 loop／try、主試法、幾何家族、接觸態、相機、姿勢、風格、系列、世界和每幕 Prompt ID。生成底圖時要求不要文字；圖完成後，由 boundary_pedestrian_try_art.py 依這份 manifest 精確排字：

- 浮動玻璃／金屬海報板約佔整張圖 **34.32%**，可選左／右位置，避免蓋住關鍵接觸面。
- 中文片名與英文片名、立體陰影字、巨型幾何方法碼、金屬漸層、浮雕深度、光環、框線及系列配色，與底圖融合成電影海報，不是角落小水印。
- 準確標示 LOOP、TRY、幾何／接觸方法、鏡頭、姿勢、風格、系列／世界、Prompt ID 和狀態。
- SVG／ASS 使用確定字串，絕不要求模型自行拼字。
- JSON sidecar 記錄來源 raster 的完整 SHA-256 和最終 SVG 作品的完整 SHA-256；圖內顯示來源 SHA 前綴供快速核對。成品 SHA 放在 sidecar，避免試圖把一張圖的完整自身 SHA 寫入它自己造成循環雜湊。

可直接把產物內的 art_label_spec 存成 JSON，使用 --label-manifest path/to/one_try_label.json 給排版器。指定 --act-id 就會自動選用該幕的正確 Prompt ID。

## 執行完整乘積

~~~bash
python bubble_break/boundary_pedestrian_product_matrix.py \
  --variants-csv docs/boundary_pedestrian/variants/VARIANT_IDS_FULL.csv \
  --catalog-doc docs/IMAGE_VIDEO_PROMPT_CATALOG.md \
  --outdir out/boundary_pedestrian/product_matrix
~~~

輸出 boundary_walker_full_product.jsonl.gz、boundary_walker_product_index.csv、boundary_walker_product_summary.json。完整編譯可能很大，建議先用 --limit 256 預覽，再執行全量。CI 會核對整個乘積與每個唯一 ID；為避免 Actions artifact 配額耗盡，工作流只保留驗證摘要和一小份完整 Prompt 樣本，而不是每次都長期儲存數百 MB 的全量包。完整包可以按上述命令重現。

## 驗收界線

編譯只表示 Prompt、軸值與 TRY 標籤規格已生成，並非所有圖像／影片都已生成。每個組合保持 PROMPT_READY、image/video NOT_RUN、pixel/continuity/video audit NOT_RUN、visual acceptance NOT_VERIFIED，直到真正有原始媒體、來源 SHA 和實際檢查記錄。物件幾何與接觸方式是鎖定條件；其他創作元素則必須有足夠多樣性。
