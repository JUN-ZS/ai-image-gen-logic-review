## 1. 藝術字（TRY／方法標示）

1. 圖裡**必須有字浮現**，藝術感可佔約 **1/3** 畫面（3D 海報層，非角落水印）。  
2. **方法名稱由排版寫死**（SVG／ASS／manifest），**不靠生成模型自行拼字**。  
3. 可標：故事名、LOOP、TRY 了什麼、幾何／接觸方法、鏡頭、風格、Prompt ID。  
4. **TRY 次數不必出現**。  
5. **REVIEW PENDING 不顯示**。  
6. **LOOP 用 SHA 記認**：`L-` + MID 圖 SHA-256 前 12 hex。  
7. 記 **SHA-256**（原圖與標字版分開；manifest 記錄）。  
8. 字要 **十分藝術感 + 3D POSTER 感** 浮在圖中。  
9. **位置可流動**：每段字自己亂走、大小不一；故事名與 LOOP **不 SET 死位置**。  
10. **不要底背色**；用特效加強（隨機）。  
11. **一句中字可大可小**。  
12. 特效**不限**：著火字、鐵槌 NEON 閃電、地上塗鴉透視等；**融入世界**，不鎖死板底板。  
13. **前幀一種字風格、後幀另一種**；VIDEO 中可同一字串，但 PRE／POST 風格極大不同。  
14. 字風格須**極大不同且融入世界**。

## 2. 前中後三幀（不可漏）

每一法／每一格：**PRE | MID | POST** 三幀。

| 幀 | 時間 | 字風格 | 物理 |
|----|------|--------|------|
| PRE | t−δt | **冷**（銅蝕／霜金／瓷） | 蓄力／遠隙／PENDING |
| MID | t0 | 臨界母版 + 全分析行 | 契約瞬間 |
| POST | t+δt | **熱**（火／熔金／焦痕） | 跟進／DONE · **字串與 PRE 同** |

- 幀連感正確：PRE 不能長得像 POST 爆炸後。  
- 同一 TRY 字串在 PRE／POST 風格變；**內容字串不變**。

## 3. SET 規則

- **每一 SET 都不同**（世界／美學／燈光不可抄上一 SET）。  
- **同一系列（SET）用同一風格**；槌形可在該 SET 內變，但風格統一。  
- **動作、角度都要變**（創作大師發揮）。  
- 打法只要表達清楚：風格／場景／鏡頭／故事都可任創，**但接觸幾何契約不可偷換**。
