# 反推 · 甲→睡衣→正衣 為何成功

## 實驗鏈
```
① 甲人 81fb
  → ② i2i 換成睡衣（清衣槽 · 姿/臉/杖鎖）
  → ③ Ref(睡衣人, 正衣 3775) 換回新甲
```

## 成功因（根）

### 1. 槽位解耦（slot decoupling）
Imagine 換衣服把圖拆成近似：
- **人槽**：臉 · 髮 · 姿 · 手 · 杖 · 鏡
- **衣槽**：布料／甲 拓撲與材質

「Change only the clothes」= 只動衣槽。  
睡衣實驗證明：杖與臉可在衣全換後仍在。

### 2. 睡衣 = 清槽緩衝（CLEAR buffer）
甲→甲（舊甲語 vs 正衣語）時，兩套 **高頻網語** 搶衣槽 → 易糊／半殘甲。  
甲→**純色簡單睡衣** → 衣槽被洗成 **低頻、無網** 的 neutral：
- 殘甲 hex 被清掉
- 新正衣進來時沒有「舊網幽靈」對抗

> **中性衣當中繼，比直接甲→正衣 更乾淨。**

### 3. 空衣板 = 純 donor（role 分離）
`3775` 正衣：**無人無臉無杖**  
Ref 時 [0]=有人姿主、[1]=空衣 donor → 模型不會把 donor 的「空頸」當人，只抽 **衣語**。  
這就是 ZYF／ETZ 的 role 閘在 Imagine 原生換裝上的對應。

### 4. 兩步 > 一步（當語系衝突時）
| 路徑 | 風險 |
|------|------|
| 甲 → 正衣 直接 | 舊網 vs 新網 語衝突 |
| 甲 → **睡衣清槽** → 正衣 | 衣槽先歸零再寫入 |

### 5. 與憲對位
| 現象 | 憲位 |
|------|------|
| 人姿鎖、衣另源 | S1 / ETZ E2 |
| 空衣板真源 | ZYF 正衣先行 |
| 清殘甲再寫 | 類似 N2R 清噪再寫 · 衣槽版 |
| 禁臉疊毒 | 本鏈 **無貼臉** · 全程 gen 換衣 |

## 一句
> **先換成中性衣清槽，再 Ref 空正衣板寫入——人槽不動、衣槽可重寫，所以成功。**
