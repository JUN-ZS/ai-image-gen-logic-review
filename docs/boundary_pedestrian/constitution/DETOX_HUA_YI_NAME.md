# 技名：解毒化衣 · DETOX_HUA_YI / DHY

> asof 2026-10-31T07:45+08 · **LOCK** · 試錯入憲  
> 用戶正名：**解毒化衣**  
> 短碼：**DHY**（Detox Hua-Yi）  
> 觸發：放大升清／ECC MATCH 後「對準了但沒改」· 衣仍母 · FULL meanΔ≈1

## 一句
**先令 dens 肉眼 rewrite 衣 → peep 硬換（禁 residual 洗）→ PROOF Δ 閘 → 才稱化衣成功。**  
對位 ≠ 有改；ncc 高 ≠ 換衣。

| ECC／GOU MATCH | 只負責 **人槽對位** · 不負責「有改」· 對完必 DHY 硬貼 |

## 禁稱
只 ECC／只 residual／只 ncc≥0.9 而 FULL meanΔ≪2 仍稱「換衣／升清成功」。
