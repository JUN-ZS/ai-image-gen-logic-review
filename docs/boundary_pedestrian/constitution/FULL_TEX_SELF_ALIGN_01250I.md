# §0.12.50.I 全紋自對順 · FULL_TEX_SELF_ALIGN（**LOCK 補**）
# asof 2026-10-30T22:11:49Z

> **用戶鐵句：** 那要懂自己對應**該所有紋**去順的修復效果 呀 · **入憲**  
> **觸發：** 杖女 1f795 修復紋效果 · 雙錘甲鏈「冇繼承」——根因係絕招曾被誤解成跨母拷 PIXEL；正解係 **同母 peep 上全部紋區自對應 → 各自順修到同一效果標準**  
> **嵌：** §0.12.50 TEX4 絕招 · 非另招取代

---

## 0.12.50.I.A 一句

**絕招要識：在本母 peep 上，自己對應出「所有紋區」· 逐區做順拓修復 · 效果標準一致（連線 · 禁螺旋 · 禁疊毒）——唔係抄上一張成功圖嘅 PIXEL。**

```
同母 peep
  → 枚舉全部紋區 T1..Tn（衣／甲／嵌線／扣／裙／袖…）
  → 每區：IP 局部 donor 或 全衣 IP 裁區
  → 每區：RRT 1A 順拓（動作鎖母）
  → 每區：P_G peep∩shape 貼
  → 效果閘：順 · 連 · 無螺旋 · 無 spill
  → 全區過閘先稱 TEX4 完成
```

---

## 0.12.50.I.B 什麼叫「對應該所有紋」

| 要 | 不要 |
|----|------|
| 同母 · 同 peep 上 **全部可見紋面** | 只修一綠圈 · 其餘放生 |
| 每區 **自出／自裁** 對應 donor | 跨母（杖女→錘甲）拷 PIXEL |
| **同一效果標準**（順連禁螺旋） | 一區好 · 鄰區亂仍 LOCK |
| 虛形：互動體唔入 peep | 錘／杖實搶 · 紋對唔準 |
| 區與區接縫連續 | 塊狀補丁邊界 |

**「修復效果」定義（效果標準 · 非圖檔）：**
1. 金／晶／嵌 **線連續**（無斷 · 無飄）
2. **拓順**（無螺旋 C 結 · 無泥線）
3. **同姿**（1A · 動作不變）
4. **peep 內**（無 spill · 無灰底鬼線）
5. **清 donor 一刀**（禁半修疊 densify）

**1f795 係效果樣板（標準）· 唔係紋素 donor。**

## 0.12.50.I.C 鐵序（全紋）

```
T0  母 + peep（綠描）+ 虛形（手杖錘虛）
T1  紋區枚舉：標 T={胸甲, 腰, 胯裙, 袖, 肩, …}
    · 格號只座標 · 區 ID 用字母／名（≠格號）
T2  ①影分身合：全衣 IP + 可選每區 detail 板
T3  for each Ti in T:
      ③RRT：Ti 殘→全→1A（姿鎖）
      ④P_G：peep∩Ti 貼 1A／IP 順紋
      閘：連線 · 無螺旋 · peep · 接縫
T4  全 T 過閘 → FINAL；缺一區 = 未完成（E-TEX-11）
T5  可嵌 SWP：只 after 全紋 1A · peep 內 · 禁全幅 GEN 疊毒（E-TEX-05）
```

---

## 0.12.50.I.D 三律

1. **全紋枚舉** — 可見紋區必須入 T 表；漏區不得稱絕招完成（E-TEX-11）  
2. **自對應** — donor／1A 必須由 **本母 peep 該區** 出；禁跨母紋素繼承（E-TEX-12）  
3. **效果一標準** — 各區達同一「順連禁螺旋」；一區失敗只重該區（E-TEX-13）

---

## 0.12.50.I.E 毒碼補

| 碼 | 禁 |
|----|-----|
| E-TEX-11 | 只修局部 · 其餘紋放生仍稱 TEX4 完成 |
| E-TEX-12 | 跨母成功圖 PIXEL 當本母紋 donor（「繼承修復圖」） |
| E-TEX-13 | 各區效果標準不一致（一順一亂）硬 LOCK |
| E-TEX-14 | 無紋區表 T · 盲全幅 GEN 當「全修」 |
| E-TEX-05 | （已有）半修再 densify 疊毒 |

## 0.12.50.I.F 一刀卡補

```
TEX4 += FULL_TEX_SELF_ALIGN
ENUM=all_visible_tex_regions_on_peep
DONOR=same_mother_IP_per_region
EFFECT_STD=continuous+no_spiral+pose_lock+peep_only
BAN=cross_mother_pixel_inherit, partial_only_claim_complete, blind_full_gen
SAMPLE_EFFECT=1f795 dress (standard only · not pixel donor)
```
