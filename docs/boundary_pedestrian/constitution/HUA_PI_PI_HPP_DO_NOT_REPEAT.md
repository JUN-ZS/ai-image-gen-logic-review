# 畫皮皮 · DO_NOT_REPEAT · HPP

1. **用錯 ratio 的生成皮當 paste 主源**  
   例：2:3 plate（ar0.67）皮膚再好，ECC 仍死 → 必須先 dens 鎖框再畫皮。

2. **為皮膚重構構圖／換姿／半臉**  
   違 face俱圓；畫皮只改材質層。

3. **磨皮過度（網紅假皮）**  
   生成級 ≠ 無孔蠟面；要毛孔／次表面／微油，不是抹平。

4. **把程序 grain 冒充生成級**  
   程序皮真實可輔；主路標 `backend=imagine_i2i` 或 `procedural` 分開。

5. **畫皮後不重測 ECC**  
   i2i 可能微漂 → 必須 gate≥0.85 才貼。

6. **setS 異姿「好皮」硬換本場**  
   只可作 skin quality ref，primary 必須 dens。
