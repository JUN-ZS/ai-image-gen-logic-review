# 黃線 GRID 格號法 · OBA §0.12.44.K
# asof 2026-10-30T17:18:36Z · f168 優化入憲

## verbatim
> 黃線 GRID 中的格的數字是 GRID 的**座標**，**不是**人的數字標記；人用**其他方法**記；格號用錯 → **毒錯人的大小規格**。

| | |
|--|--|
| 格數字 | GRID 座標 only |
| 人 | 字母 A.. ／ UUID · peep 量 |
| s | peep_h/w only · **永不**格邊長 |
| 毒碼 | E-OBA-02 · E-OBA-14 |
| 禁句 | 「格號就係人號」「跟 GRID 格放大」 |
| 自審 | 數字在格心 · 字母在 peep |
