## 病理（病毒機制）

```text
正推鎖 + 反推 Verify + CONST 長文 + 多 Ref + 姿態 δ + 禁語牆
        ↓  同幀同時灌入
生成器注意力被「服從條款」佔滿
        ↓
放棄高頻物細節與雕塑一致性（降智）
        ↓
為滿足「上舉／有桿／握桿」輸出可通過閘的 **簡化變型物**
```

即：**閘門通過 ≠ 物同源。** 過干預令程式只優化「過閘」，不優化「仍是原物」。

```text

4) 干預上限：同幀約束條數封頂；超限先減鎖再生成
5) 原程式優先：F0/FT 像素與風格 > 口頭正反推修辭
```
