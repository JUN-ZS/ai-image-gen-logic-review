> 源：F0 `2ce551c4` · FT `0e6ff589` · 動作「舉環到臉旁 + ZOOM IN + 微俯視」· 30 幀  
> 問：出錯圖能否在**不降智**下鎖死？REF vs 貼？根因？除毒法？

---

## 0. 一句結論

| 問 | 答 |
|----|-----|
| 出錯圖能否不降智鎖？ | **能**——鎖的是 **Ω／Verify／δ**，不是灌長文逼模型「變乖」 |
| 根因是 REF 還是貼？ | **執行把 REF 當貼** → 每幀重畫臉／械 → 改物／重影／跳級 |
| 除毒？ | **殺幀 + 本段重出 + 硬貼閘**；禁止用更長憲文「再干預一次」（OIDV） |

**正推不是長小說。** 指紋級即可；長文化 = OIDV 溫床。

## 4. 根因鏈（不是「模型笨」單因）

```
F0 有物真相
  → 執行：imagine_ref / img2img 整幅重生（REF soft）
  → 每幀重新抽樣「環長怎樣」
  → 無 Verify 硬閘
  → E-01 改物 / E-04 臉漂 / E-02 軌漂
  → 人用更長 prompt「一定要…」→ E-06 OIDV → 更改物
```

**REF ≠ 貼**

| | REF（現多用） | 貼（憲要） |
|--|---------------|------------|
| 本質 | 條件重生 | 像素／裁區合成 |
| 臉 | 易 GFV | HARD 臉 crop warp 貼 |
| 物 | 易改拓 | 剛體 warp 或 F0 械貼 + 只動握姿遮罩 |
| S 灰底 | 常重畫 | F0∩ 灰 mask 貼 |
| 算力 | 全圖 | 只 M 區 gen |

根因公式：

```
Error = SoftRef(全圖)  −  Paste(臉,S,械剛)  −  Verify
```

當 `Paste=0, Verify=0` → 錯必然累積；**與是否 HTM／是否中途加插無關**（加插只放大暴露）。

## 5. 「不降智」下如何鎖？（OIDV 反向）

降智 = 用**過密約束文**換表面服從，模型簡化幾何。  
不降智鎖 = **短指紋 + 硬閘 + 小 Ω**。

### 5.1 三層鎖（由鬆到硬）

```
L1 指紋（prompt 最多 2～4 短句）
   「開月環+轂+桿 · 握桿 · 本步 halfway · 單幀」

L2 結構閘（生成後 · 程式/人工）
   parts_count · 環開月非實心錘 · 無拼版 · 無過頂若 t< t_high_forbid

L3 像素貼（真鎖）
   臉: paste(F0_face, align)
   S:  paste(gray)
   械: 可選 paste(F0_weapon_mask 剛體變換) 或 只 M=臂 gen
```

**鎖在 L2/L3，不在把 L1 寫成憲法全書。**

### 5.2 δ 單調（防 E-02）

```
h_ring(t)  單調 ↑ 至 臉旁高度（本動作）
zoom(t)    單調 ↑
pitch(t)   單調 → 微俯
禁止: h_ring 先 > 頭頂 再 ↓（繞路）
```

進度關鍵幀應用 **參數 t∈[0,1]** 描述，而非自由「raise more」語。

### 5.3 Ω 最小集

```
Ω = { R_肩, R_肘, R_腕, T_械剛體, dolly, pitch }
禁止 Ω = { retopo, 加件, 拼版, 換臉重抽, 握環 }
```

## 6. 除毒法（可操作）

### 6.1 單幀毒

| 毒 | 除法 |
|----|------|
| E-01 改物 | **Kill** · 本段頭尾 Ref 重 mid · 指紋一句物 · L2 拓閘 |
| E-02 繞路 | Kill 繞路點 · 用 `t` 線性 mid(F_a,F_b) 且 a,b 已在單調軌上 |
| E-03 拼版 | Kill · prompt 加「single full-frame only」· 仍出則 Kill 不修 |
| E-04 GFV | **臉 HARD 貼** F0 · 禁止第三張 soft 當貼 |
| E-05 糊 | Kill · 禁 motion blur 語 |
| E-06 OIDV | **刪長文** · 回短指紋 · 勿疊加「必須完美…」 |

### 6.2 段毒（#09–12）

```
不: 全 30 重跑
要: 定合法錨 A=#08 右前 · B=#13 臉旁
    刪 09–12
    只對 (A,B) HTM 加密 2～4 幀
    每幀 L2+L3
```

### 6.3 流程級除毒（下一 run 預設）

```
1. 編 CONST_F0 短指紋（已有思想 · 落 JSON）
2. 出 FT · Verify 對 F0 拓
3. 進度鍵只用 t=k/N · [F0,FT] Ref · 短句
4. 每幀: gen → Verify → 臉貼 →（可選械貼）→ 入列
5. 失敗: Kill · 本段 redo · 禁止加長 prompt 迴圈
6. 中途加插: 允許 · 同 4 · 只動本段頭尾
```

### 6.4 公式（收束）

```
合法幀 ⇔ SoftRef_姿(頭,尾,t)  ⊕  Paste_臉(F0)  ⊕  Paste_S?
         ∧  Topo(F0)  ∧  Mono(δ)  ∧  ¬拼版  ∧  ¬OIDV長文
```

**不降智** ⇔ 約束力在 **Paste + Verify**，不在 **散文密度**。

## 7. REF / 貼 · 決策表

| 需求 | 用 |
|------|-----|
| 姿／角度／zoom 插值 | REF 頭尾 · **短** halfway |
| 臉一致 | **貼** F0（或 a8b 若同憲） |
| 灰底穩 | **貼** S |
| 械拓死 | L2 閘 + 可選械剛貼；**勿**只靠 REF 長描述 |
| 身份跨鏡頭 | 貼 > soft 多 Ref |

## 8. 對 RAISE30 的判決

| 區 | 判決 |
|----|------|
| F0 / FT | **合法錨** · 拓大體可當 CONST |
| 前段 00–08 | 大致可用 · 仍建議臉貼 |
| 09–12 | **E-02 繞路** · 除毒=段殺重 mid |
| 13–28 | 主軌可用 · 近景臉旁成立 |
| 全列 | **未上 L3 貼** → 不能稱「憲已鎖」· 只能稱「軌近似」 |

**可否不降智鎖？**  
→ **可以**：對 09–12 段殺 + 線性 mid + 臉貼 + 拓 Verify；**不要**再灌長鎖文。
