## 0.12.33.A 根命題

生成器**已有**「物件另一角度再生成」能力。  
失控不是缺 3D 想像，而是：

```
想像時根因自由度仍 free → 每幀重抽先驗 → 換物／換柄／換拓
```

**提醒鎖** = 令轉角／zoom／追尾 = **同一物的投影**，不是 **另一把**。

```
提醒鎖 = 模板格物錨 A_i × 不變式 R_ij × 根因區 N 鎖（自 F0）
```

```
O ≈ A_grip

Ω_cam(t) 只動相機／姿
根因帶：N_i = N_i(F0) · Soft 禁寫
```
