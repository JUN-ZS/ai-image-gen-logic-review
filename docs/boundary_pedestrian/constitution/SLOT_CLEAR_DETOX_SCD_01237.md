## 0.12.37.C 掃毒功能（操作）

### 槽模型

| 槽 | 內容 | 本招 |
|----|------|------|
| **人槽** | 臉／髮／姿／手／杖／鏡／場 | **硬鎖** · 不掃 |
| **衣槽** | 布料／甲 拓撲＋材質 | **可掃可寫** |

### 鐵序（不可顛倒）

```text
S0  人主圖  PERSON（姿·臉·杖 完整）
S1  清槽    → 中性衣（睡衣／素色／無高頻網）  CLEAR_BUF
S2  寫入    Ref(CLEAR_BUF_人, 正衣_donor)     空衣板 role=lock
S3  驗      無舊網幽靈 · 人槽仍在 · 衣=donor 語
```

### 中性衣規格（CLEAR_BUF）

| 要 | 不要 |
|----|------|
| 低頻 · 無 hex／金屬網 | 另一套複雜甲 |
| 絲／棉／素色 pajama 級 | 仍帶舊甲局部 |
| 手／杖仍握（人槽證明） | 丟掉武器當「脫衣」 |

### Imagine 直換（推薦）

```
# S1 清槽
i2i(PERSON, "Change only clothes to plain soft pajamas. Keep face hair pose hands staff.")

# S2 寫 donor

    "Change only clothes to the armor dress in the second image. Keep face pose staff.")
```
