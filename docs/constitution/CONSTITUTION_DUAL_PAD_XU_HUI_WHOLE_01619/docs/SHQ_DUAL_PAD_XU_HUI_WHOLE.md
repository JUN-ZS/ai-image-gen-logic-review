**对物 = 整体辨识**；回图 = 座洞虚回 + 四态扣底 + 强心针；**框回锁 / 座洞 不被 freeframe elev 污染**。

## 正：两次虚回
```
R1  稍 PAD    认主主体 → 虚回槽1 → 稍后 LOCK 四态扣+底（座洞金）
R2  PAD加大   再读物（完整度）→ 虚回槽2 → 通过才 强心针
回  peep-lock elev → hard 入 R1 座洞（框回锁）→ 反 outside=0 + TEX
```

## 金句
1. 第一轮定座；第二轮求完整。
2. 强心针在整体认过之后。
3. freeframe elev 永不直接进座洞。
4. 根 PAD 不动；两轮差值只活在沙盒。
