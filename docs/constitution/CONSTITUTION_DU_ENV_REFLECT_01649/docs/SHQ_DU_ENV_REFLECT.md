# 独·环境反射（01649）

## 问
全量环境才能解释的反射，如何用一物生的「独」做？

## 答（一句）
**独 = 洞像素主权 + 全相身份；生 = 仍在全景绿座上填。**  
环境在第一参考里，不是黑底断环境。

## 拆
| 字 | 义 |
|----|-----|
| 独 | 1物1链、MARK 互斥、全相 BACKUP 身份 |
| 环境 | 绿座图=同机位全景（台/邻/光） |
| 生 | 轴.反射.生([绿座,全相]) ⊙ MARK |
| 反 | outside=0 环境底不动 |

## 方程
```
反射_i = f(环境|绿座全景, 身份|全相_i, 座|MARK_i)
独_i   = 所有权(MARK_i) ∧ 身份(全相_i)
生_i   ≠ freeframe(全相_i) 硬贴
```

## 步步
后→前叠：后排先坐，前排独生时邻物已在绿座条件里。

## 限
互反射要 2 轮或景级调和；未绿座物的倒影只留在底。
