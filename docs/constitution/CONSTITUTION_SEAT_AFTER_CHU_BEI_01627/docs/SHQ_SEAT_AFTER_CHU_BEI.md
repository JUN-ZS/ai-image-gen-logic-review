## 1. 問題重述

> 外力已經除了背，那物的**座洞鎖** LOGIC 上還需要 **CC**？還需要 **差分**？

在 **步步為一** 下，一次只對一物。

---

## 2. 倒反證 A ·「除背後不必再有座」

**假設：** 外力除背成功 → 直接 hardpaste 回圖 = 座洞鎖完成。

**必炸：**

1. freeframe 除背 → 物在畫布中心／特寫，**失去 L0 座標**（E-WLF3-01 無洞回）。
2. 有身份、無座位 → 回錯位（你已留錯教材）。
3. 步步為一要後→前堆疊，沒有 S0 座就無法比深度、無法前蓋後。

**結論：** 除背 **≠** 座洞鎖。假設不成立。  
→ 座洞鎖在除背後**仍然必要**（至少：凍 peep 窗 + MARK 形）。

---

## 3. 倒反證 B ·「座洞鎖邏輯上**必須** CC」

**假設：** 沒有 connectedComponents 就不能座洞鎖。

**反例（單物 · 步步為一）：**

```text
已知：S0 上 peep 窗已凍（抽出時記錄 y0,y1,x0,x1）
     外力除背 → CLIP 身份（可 peep 內）
     外力除主 → 同機 L1
局部：M = Support(|peep0 − peep_L1|)  或  EDIT 色相／魔棒層
→ hard @ (M 嵌回 S0)
```

全程**可以零次全域 CC**。CC 只是「全圖變區裡拆 N 物」的**分件器**。

**步步為一** 本意：一次一物 → 分件可在：

- 先讀／discovery 列出 N 窗，或  
- 人工／外力指定一窗  

之後每物圈內 **不必再 CC**，甚至 discovery 的 CC **不當座**（01626）。

**結論：** 座洞鎖 **邏輯上不必然需要 CC**。  
CC = 可選的 **多物發現／拆件** 工具，不是座的定義。

| 場景 | 要不要 CC |
|------|-----------|
| 單物 · 窗已凍 | **不需要** |
| 多物 · 步步為一 · 窗已由先讀給出 | **不需要**（再 CC 易亂扣） |
| 只有一張全圖差分、尚未分窗 | **可用 CC 做 discovery**，結果**只當窗，不當座** |
| 一窗內多碎塊要合成整件 | 可用 CC／形態學，屬 **整件補洞**，仍非「全圖亂扣」 |

## 4. 倒反證 C ·「除背後**不必**差分」

**假設：** 已有除背 CLIP，座可完全不靠差分。

**分叉：**

### C1 · 有「抽時凍窗」+ 可對齊的 CLIP 遮罩

若 外力除背 **同機同框** 產出 **與 L0 對齊的 alpha／剪影**：

```text
M_seat = CLIP_alpha 重采样到 S0   （或 peep 内 alpha 嵌回）
```

此時 **可以不跑 \|L0−L1\| 差分**，因為 **形已由除背遮罩給出**。  
但必須滿足：**同機 · 可對齊 · alpha 可信**。  
勤力：仍建議 **反扣一次**（有物 vs 無底 或 L0 vs L1）做 **驗票**，不作為唯一主源也可。

### C2 · 除背是 freeframe／重構圖（常見）

CLIP **無 S0 對齊** → 沒有差分（或凍窗）就 **沒有座**。

```text
身份 = CLIP
座   = 仍要 peep0@S0  +  (差分|EDIT扣|抽時bbox)
```

**倒反：** 若堅持「除背後永不差分、也不凍窗」→ 必回錯位。假設在 C2 **不成立**。

### C3 · 有同機 L1（除主）時

差分是 **最硬的座證**：

\[
M \subseteq \mathrm{Support}(|L0-L1|)
\]

與 SS驗.清「無底→扣」同構：無底可以是 **L1 全景** 或 **同窗 peep_L1**，不是全圖亂 CC。

**結論：**

| 條件 | 差分是否邏輯必須 |
|------|------------------|
| 除背 mask 已與 S0 bit 對齊 | **非必須**（可作主座）；勤力仍可反查 |
| 僅有 freeframe CLIP | **必須** 另有座源：凍窗 peep + 無底扣／L0−L1／EDIT 洞 |
| 步步為一 · 無底同窗 | **局部差分（或局部 EDIT 扣）** 是座形主路徑；**不是**全圖亂扣 |

## 5. 總表（勤力 · 一步不偷）

```text
外力除背  →  身份（CLIP）
外力除主  →  無底舞台（L1）
座洞鎖    →  形@S0 + 窗契約
```

| 工具 | 角色 | 邏輯必須？ |
|------|------|------------|
| **CC** | 多物發現／拆窗／碎塊合併 | **否**（步步為一有窗後可不用） |
| **差分** | 有物×無底 → 證座形 | **有對齊 mask 時可免主路徑**；**無對齊時必須有等效座源** |
| **EDIT 扣／色相** | 差分的外力同胞 | 可與差分二選一或 ∪ |
| **凍 peep 窗** | 尺度與位置契約 | **是**（無窗則無步步為一） |
| **SS驗.清** | 無底→扣→硬鎖不移位 | **是**（回位門） |

**禁止偷步：**

1. 全圖 CC 當座（亂扣）  
2. 除背 freeframe 當座  
3. outside=0 alone 當完成（無 seat_born）  
4. 步步為一卻一次差分糊 N 物當 N 座

```text
     ※ 此步「差分」是局部證座，不是全圖亂扣

```

**CC 出現位置（若出現）：** 僅 discovery 或一窗內整件修復；**寫进 Bus 标成 discovery，不标成 seat。**

## 7. 金句

1. **除背給身份，不給座位；座位要鎖。**  
2. **CC 不是座的本體；亂用 CC = 全圖亂扣。**  
3. **差分是證座的常用硬手段，不是拜物教——有對齊 mask 可替，無座源不可免。**  
4. **步步為一：一窗一扣一補給一鎖；後→前蓋。**  
5. **倒反證：無座必錯位；無必要 CC 而強 CC 必碎物。**
