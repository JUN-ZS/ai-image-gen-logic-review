# SS.验.PAD大 · write 01614

## 定义
在 SS验.清 / 清+A / 虚回 链上，**强制高 PAD** 冻座 peep，再外力 densify，**心强缘弱** 加权回位。

## 金方程
```
peep  = SRC[pad_high]          # PAD≥0.28，默认 0.32
LOCK  = FREEZE(pad_box, M)     # 虚回不重开
elev  = 外力 densify(peep)
I     = (1−w)·base + w·blend(peep, elev)   # 心强缘弱
```

## vs 低PAD
| | 低PAD | PAD大 |
|--|------|------|
| peep | 易切边 | 上下文足 |
| 回贴 | E-PAD-01 风险 | 1:1 pad 对齐 |
| elev | freeframe 更易漂 | pad 锚定 虚回 |
