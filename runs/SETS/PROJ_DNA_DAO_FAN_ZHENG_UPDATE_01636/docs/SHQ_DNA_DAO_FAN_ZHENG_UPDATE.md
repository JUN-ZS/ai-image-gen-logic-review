# DNA·倒反证更新 · write 01636

## 你问的洞
> 为什么知道用新法后，不更新冲突的 CC MARK 旧法等等？

因为缺 **强制废止协议**：新闸只「加上去」，旧法仍 LIVE → **双轨**。
RUN 可偷偷走旧 CC MARK / outside alone，报告仍绿。

## 倒反证（强制更新）

```text
假设：旧法 L 仍合法  ∧  新法 N 为宪之真
则：存在同物同步 RUN：
      claim 依 L → PASS
      claim 依 N → FAIL
但：合规唯一时，PASS ∧ FAIL 不可同真
故：L 不得再合法
∴  status(L) = DEAD，并写入 METHOD_REGISTRY
```

### 例（APPLE 已实证）
- 新：框内闸 cover=0.62 → **FAIL**（01634）
- 旧：outside=0 → **PASS**
- 若两法都 LIVE → 同 RUN 真假绿 → **矛盾** → 旧 outside alone 必须 DEAD

### 例（CC MARK）
- 新：MARK := 除背影（01631）
- 旧：乱 CC / 色带窗框造 MARK
- 两套 MARK 同称座 → 影扣回定义瓦解 → **矛盾** → CC 旧法 DEAD

## 入宪义务（新法 write 时）

4. 自检双轨 → **E-DUAL-TRACK-01 FAIL**
5. 无 conflict 表 → **E-NO-CONFLICT-TABLE**

## DEAD（即刻）

- 色带膨胀、窗矩形 MASK

- 無背 freeframe 无尺锁直贴

- 尺/框/RATIO 闸 = 只判不改影
- 轴 = 虚回认位 only
- 步步為一；外力GROK 四态

## 金句
1. 新法真 → 冲突旧法必须死，否则倒反证破产。
2. 加闸 ≠ 更新；**废止** 才是更新。
3. 双轨 = E-DUAL-TRACK-01，整次 claim 作废。
