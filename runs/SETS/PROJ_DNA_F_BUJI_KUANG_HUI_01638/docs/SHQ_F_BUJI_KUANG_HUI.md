## 语义病
**lock 影 / 影扣回 / 影技术** = E-SEM-YING-01  
从来不是主技术名；易混剪影魔术，**偏离** `[(生,除,洞,扣)×(反)]`。

## 真 RELATE
```text
除  离开（有物→無底）
扣  证洞（不乱CC重开）
洞  座位 MARK（框坐标）← 不是「影技术」
生  独自补给：1物=1次 peep elev/densify
反  洞外0 · cover/尺 · 框回锁

框回鎖:
  R = B⊙(1−M) + Supply_i⊙M
  步步為一 后→前
```
