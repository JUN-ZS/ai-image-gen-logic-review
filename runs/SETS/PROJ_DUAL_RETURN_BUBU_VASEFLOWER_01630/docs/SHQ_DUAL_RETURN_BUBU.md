## 2. VASE 为何要连花
认物除背 = **整件语义**（瓶+茎+花），不是只扣蓝肚。
窗内色带∪除背 alpha，**仍非全图乱 CC**。

## 3. 步步為一 后→前
后层先贴补给；前层盖住后层像素；被挡的后层仍占过座=定位功劳。
