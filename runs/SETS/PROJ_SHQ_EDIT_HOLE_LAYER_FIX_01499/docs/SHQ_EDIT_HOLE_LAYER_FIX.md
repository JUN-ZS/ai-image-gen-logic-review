# 洞错位=偷步 · EDIT 多层洞回（01499）

## 诊断
洞错位 → 一定偷步：少了 EDIT 除背/有无头×有无背，用剪影 hardpaste 代替**洞框内 INPAINT**。

## 必做 EDIT 层
| 层 | 内容 |
|----|------|
| L0 | 有头有背 |
| EDIT 除背 | 有头无背 |
| EDIT 除头 | 无头有背=洞座 |
| EDIT 洞内 INPAINT | 高清头在洞框中生 |
| 备选 | EDIT 头→纯色 供 detector 全扣 |

## 法
HD 在洞框 INPAINT → 不对错位。扣洞关系层不可偷。
