## 2. 全 PROJECT 正典：[(生,除,洞,扣)×(反)] 圖是什麼

**源：** `SHQ_FOUR_ANTI_ALGEBRA_ARCH.md`（01448）· 01386 · 01436 · F8

> 洞是形，除是態，扣是證，生是填；反是每一步的鏡子。  
> **8 格 = {生,除,洞,扣} × {正,反}，不是四個按鈕。**

| 格 | 圖（正典） | 不是 |
|----|------------|------|
| **正除** | L1 外力 EDIT 除頭後 **全幅** | 手擦、假 empty |
| **反除** | L0 有頭 **全幅** | — |
| **正扣** | \|L0−L1\| Diff 證洞 | 自 peep 冒充 |
| **反扣** | Diff 反查疊 SRC | 省略反 |
| **正洞** | \(M_{hole}\) 剪影 | peep 框、AABB |
| **反洞** | \(1-M\) 洞外 bit-exact | — |
| **正生** | **洞內** HD，座標系=**SRC** | **freeframe 特写主權**、黑底頭特寫當完成 |
| **反生** | 生後 peep ↔ 生前 peep 鎖尺 | elev_remap |
| **正回** | hardpaste(SRC,M,scale_lock(GEN(peep))) | freeframe 裁貼當回 |
| **反回** | 洞外 diff=0 板 | outside 自嗨 |

**State Bus 圖鍵：** SRC · L1 · M_hole · peep · elev · RETURN · ANTI  

**公式：**

```text
RETURN = hardpaste(SRC, M_hole, scale_lock(GEN(peep_M)))
         s.t. out[¬M] = SRC[¬M]
```

**接口不變量：** 同機位 · 同洞 · 同 peep bbox · elev_remap=false · outside=0 · scale-lock
