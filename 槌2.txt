# PROMPT 成長記錄｜從隱喻分鏡到可畫公式（全文參考版）



用途：把整段迭代編成可複用地圖。公式說明**進程方向**，不是堆形容詞。

讀法：第 0 節看線 → 第 2 節查「那時加了哪句、為何轉」→ 第 3 節複製現用公式。



角色鎖定：**原女主**（真實系亞洲女戰士，長直深棕髮、柔和五官、大眼、自然妝、黑皮戰鬥服）。

不是 玥Itsuki，不是動漫惡魔裝。出圖用 clean text-to-image，禁止連續 Img2Img 疊圖。

## 0. 進程方向（一條線）



```

原故事隱喻

→ 可拍之物（泡泡／爪機／奶昔／碎玻璃／天台）

→ 可愛 INS（高頻換鏡頭、道具） ← 防靜死

→ 真實攝影 + 六棚換景 ← 像真 MV 換棚

→ 影像契約 16:9／光暈／顆粒／宏大／角色弧

→ 雙世界《邊界行人》（A 保護泡 / B 破碎真實）

→ 3 分鐘 ≈ 54 鏡；精簡 24 關鍵卡

→ 柔抱同一容器 × 大錘打碎（同一雙手）

→ 文字對 ≠ 圖 FOLLOW

→ 剛體：END FACE ≠ CHEEK；動力鏈；接觸→裂源

→ AXE 易畫、HAMMER 難畫

→ 取消「先真斧再換錘」（會變成實相斧／重解接觸）

→ 可視化編譯：真值 → 可畫 primitive → 才餵模

→ 可簡可繁（CORE + 槽 + k 層；錘是 CONST）

→ 厚十字／正交／plus-sign：「點打都中」= 結構解

→ 十字仍被畫成 T 或複雜多面錘

→ 多向槌面指向各方 → 頭合成圓；武器仍是一把錘（一柄一頭）

```



方向一句：



```

故事層永遠有效。

力學層變成審核器，不直接餵模。

生成層只吃「能畫成輪廓」的句子。

武器層用結構降低錯面，不靠再寫一頁 XYZ。

```



層疊（開新題按這張加，不要一次全塞）：



```

L0 六幕引擎 + 雙世界角色弧

L1 影像契約（16:9／光暈／顆粒／宏大／臉鎖）

L2 每幕獨立極致場景 + 服裝大變

L3 CORE 可畫核（人／錘／靶／觸點／斜柄）

L4 武器結構（十字 → 正交四端 → 多向圓頭）

L5 變量槽（衣／景／光／FX）最後加

L6 像素審核（只信畫面）

```

## 2. 階段迭代（要什麼 → 加哪句 → 為何轉）



### S0 超現實 50 鏡



抽象必須變成可拍物。單一神祇棚會靜死。



### S1 可愛 INS



隱喻仍在，物換成泡泡糖、甜點櫥窗、抓娃娃機、自拍濾鏡、復古溜冰。

轉向：偏 AI 美化、Q 版，不像人家真 MV。



### S2 真實風 + 換棚



每幕不同實景、同一張臉。

轉向：還要 16:9、光影顆粒、宏大、角色弧。



### S3 影像契約



見 1.4。

轉向：要「她走於兩個世界」，不能只換皮。



### S4 《邊界行人》公引擎



六幕掛上 A／B。可出 24 卡或 54 鏡。

轉向：要柔與大錘砸同一容器的對比。



### S5 柔 × 大錘



```

同一角色 · 同一容器

先極柔護住 → 再親自用大錘砸開

不是恨，是還自由

人永遠小於容器；選擇永遠大於她

節點：護 → 攀 → 界（一手罐一手錘）→ 舉 → 砸 → 跪 → 對 → 放

```



柔鏡不要錘；錘鏡不要斧。對比靠剪輯或左右分鏡。



### S6 剛體課（此後力學只當審核）



```

FACE ●────────────● FACE ← END STRIKING FACE

│ HEAD │

│ CHEEK │ ← 長側壁，禁止領先

└────┬─────┘

│ HANDLE（中眼，⊥ 頭長軸）

```



- 打的是端部 FACE，不是 cheek、不是柄

- 「小面」＝端部平面，不是把錘臉縮成針

- END FACE 是揮動的終端幾何，不是另貼上去的臉

- 裂必須從接觸中心長；目標在接觸前應仍完整



失敗碼：CHEEK-FIRST／SIDEWAYS／STATIC-END-FACE／HANDLE-FIRST／PRE-FRACTURE／CONTACT RE-SOLVE／AREA BIAS。



A（有力但 cheek 先到）與 B（端面對但像按住）是同一錯：把「人的姿勢」和「錘的接觸」當兩個物件。



```

錯：有力的人 + 在目標旁的錘 + 碎裂特效

對：BODY → HANDLE → HEAD → ACTIVE END FACE → CONTACT → FRACTURE

```



### S7 取消真斧中間層



斧好畫（薄刃插入＝高辨識 primitive）。

先畫真斧再換錘 → 模型學會出斧，換頭時重解接觸，大面積 cheek 又勝出。



留下的理解（可想斧，不可畫斧）：



```

若是斧：絕不用側面橫推，只用鋒切開

輸出必須是錘：鋒的角色 = ACTIVE END FACE

斧的刃側 = 錘的 CHEEK → 永不主力

畫面永不畫斧

```



### S8 受力點／禁槍線／V5 人審式



```

唯一 C = ACTIVE END ∩ 受擊面

n_HB ≈ − n_TARGET ，只共 C

柄軸 ≠ D ，人軸 ≠ D ，人→球心 ≠ D

錘軸 ⊄「接觸點→球心」（約 45°／對角，不是穿心矛）

D = aX+bY+cZ ，禁止純 ±X 把全世界排成一支槍

```



V5 給人審，不整段餵模。



### S9 根問題：PROMPT 有 ≠ 圖 FOLLOW



```

PROMPT SPACE（D、C、法線）

↓

？ ← 缺可畫中介；模型用先驗填＝大塊金屬貼球

↓

IMAGE SPACE（輪廓／遮擋／接觸）

```



管線：



```

PHYSICS TRUTH → VISUAL PRIMITIVE COMPILER → GENERATOR → PIXEL AUDIT

FAIL：修編譯器，不堆真理公式

```



單張畫不出的東西（速度、力矩、T−1）只審不餵。



編譯例：



```

```
| 真值       | 可畫句                 |
| -------- | ------------------- |
| n_HB = D | 小平端面是唯一碰玻璃的金屬輪廓     |
| 禁 cheek  | 長側壁在側／後，不吻玻璃        |
| 非同軸      | 人＋柄＋球心不是一條螢幕直線；擊點偏心 |
| 裂從 C     | 裂只從錘碰到的點長出          |
```

```



### S10 可簡可繁 V6（餵模層）



生成器解的是：女人在左、手上有錘、右大球、金屬碰到玻璃、裂從那點開、柄是斜的。



```

CORE

woman_LEFT + HAMMER_IN_HANDS + TARGET_RIGHT

+ touch = striking_FACE ∩ shell

+ cracks_FROM(touch)

+ handle_ANGLED

+ body_NOT_on_gun_line

錘是 CONST，不是可選道具

```



保險句（加場景必帶）：



```

she is still holding the sledgehammer

the hammer is in the picture

do not replace the hammer with a hand touch

both hands on the handle

```



k=0 核 → 先衣再景 → 最後光／FX。diner／霓虹高危。一掉幾何就回到 k=0。



k=0 最短模板：



```

Single 16:9. Woman left, real hammer in both hands, huge glass sphere right.

Striking face touches the glass; cracks only there.

Handle angled — not a spear through the ball center.

Body not on one line with handle and ball center.

No axe. No text.

```



### S11 實驗支線（找 primitive，不成片）



雙刃斧橫斬浪／冰波 → 棒橫斬冰球 → 再回到錘。

正式成片禁止出斧。



### S12 結構解：厚十字／正交／plus-sign



十字夠用；要**加厚**，不要拉長垂直臂。

禁止連續 Img2Img。

錯路：4 把錘、4 把獨立錘、2D 平面十字、一柄四頭、教學圖畫成單頭 T。



**正交厚十字（曾用公公式）：**



```

a massive extremely thick cross-shaped war hammer,

the hammer head features a robust orthogonal design

with both prominent vertical and horizontal thick solid striking blocks,

featuring heavy flat striking faces on all top, bottom, left, and right ends

```



為什麼這樣寫：`orthogonal` 逼垂直相交；`vertical and horizontal` 逼兩臂都在；`top, bottom, left, and right` 逼四端都有面。



實測：厚與四向出來了，模型仍常畫成「厚重多面戰錘」，不是乾淨 plus-sign（+）。



**更乾淨 plus-sign 句（補強）：**



```

a massive thick plus-sign cross-shaped war hammer,

the hammer head is a clean orthogonal plus-sign formed by

one thick vertical solid rectangular bar and

one thick horizontal solid rectangular bar crossing at the center,

four equally thick solid rectangular striking blocks pointing

top bottom left and right, each end has a heavy flat striking face

the hammer must look like a thick metal plus-sign cross

not T-shape not X-shape not single head

```



Negative：`T-shape, single head, X-shape, thin arms, missing vertical arm, missing horizontal arm, thin hammer`



### S13 多向槌面合成圓頭（現用武器結構）



「由槌頭組成的圓」曾被畫成：女主站在槌頭圓環裡，或場景裡一顆錘星球。錯。



正確：



```

一把錘 + 一條柄 + 一個頭

頭上密鋪多個扁平槌面，面朝四面八方

所以頭看起來是圓

圓是結果，不是佈景

打玻球時，朝目標的那一面先觸

```



```

```
| 是          | 不是          |
| ---------- | ----------- |
| 仍是錘        | 晨星／鏈錘／刺釘狼牙  |
| 一柄一頭       | 很多把錘圍成圈     |
| 面是扁平打擊面    | 只為了圓而變成刺球   |
| 怎麼揮都有一面能對上 | 2D 加號只在一個平面 |
```

```



殘餘風險：模型愛畫「立方凸塊密鋪」（偏釘頭棒）。若要更像真正大錘端面，強調 `wide flat sledge faces`，禁 `spikes, studs, mace flanges`。

## 4. 像素審核（出圖後才填）



- [ ] 有錘，雙手握柄

- [ ] 無斧、無鏈、無刺球

- [ ] 一柄一頭（不是圍著她的圈，不是場景裡的錘星球）

- [ ] 宣稱十字則必須豎臂＋橫臂都在；宣稱圓頭則面朝外、頭讀得成圓

- [ ] 接觸是打擊面，不是長側壁拍打

- [ ] 柄有角度，不是人–柄–球心一條槍

- [ ] 裂從接觸點長

- [ ] 無 H-A／H-B／C 等教學字漏進成片

- [ ] 仍是原女主設定



含糊＝未過。修結構句或編譯句，不修「再 powerful」。

## 5. 公式在修什麼（對照表）



```

```
| 公式             | 在修的問題              |
| -------------- | ------------------ |
| 隱喻→物           | 抽象不能拍              |
| 換棚＋鏡頭高頻        | Img2Img 靜死         |
| 影像契約           | 不像真 MV             |
| 雙世界＋角色弧        | 場有敘事空              |
| 柔×錘同一容器        | 缺對比                |
| END FACE／動力鏈   | 錘在畫面裡但沒在打          |
| 取消真斧中間層        | 畫成斧、接觸被重解          |
| 只共 C、禁槍線       | 同軸矛刺               |
| 可視化編譯          | 公式對、圖不跟            |
| 錘 CONST＋k 層    | 加場景錘消失             |
| 正交厚十字          | 永遠打錯面              |
| plus-sign 四臂寫死 | 十字變成 T／多面錘         |
| 多向圓頭           | 十字仍不穩；圓是「各方都有面」的結果 |

### S0 超現實 50 鏡

抽象必須變成可拍物。單一神祇棚會靜死。

### S1 可愛 INS

隱喻仍在，物換成泡泡糖、甜點櫥窗、抓娃娃機、自拍濾鏡、復古溜冰。
轉向：偏 AI 美化、Q 版，不像人家真 MV。

### S2 真實風 + 換棚

每幕不同實景、同一張臉。
轉向：還要 16:9、光影顆粒、宏大、角色弧。

### S3 影像契約

見 1.4。
轉向：要「她走於兩個世界」，不能只換皮。

### S4 《邊界行人》公引擎

六幕掛上 A／B。可出 24 卡或 54 鏡。
轉向：要柔與大錘砸同一容器的對比。

### S5 柔 × 大錘

```
同一角色 · 同一容器
先極柔護住 → 再親自用大錘砸開
不是恨，是還自由
人永遠小於容器；選擇永遠大於她
節點：護 → 攀 → 界（一手罐一手錘）→ 舉 → 砸 → 跪 → 對 → 放
```

柔鏡不要錘；錘鏡不要斧。對比靠剪輯或左右分鏡。

### S6 剛體課（此後力學只當審核）

```
FACE ●────────────● FACE ← END STRIKING FACE
│ HEAD │
│ CHEEK │ ← 長側壁，禁止領先
└────┬─────┘
│ HANDLE（中眼，⊥ 頭長軸）
```

- 打的是端部 FACE，不是 cheek、不是柄
- 「小面」＝端部平面，不是把錘臉縮成針
- END FACE 是揮動的終端幾何，不是另貼上去的臉
- 裂必須從接觸中心長；目標在接觸前應仍完整

失敗碼：CHEEK-FIRST／SIDEWAYS／STATIC-END-FACE／HANDLE-FIRST／PRE-FRACTURE／CONTACT RE-SOLVE／AREA BIAS。

A（有力但 cheek 先到）與 B（端面對但像按住）是同一錯：把「人的姿勢」和「錘的接觸」當兩個物件。

```
錯：有力的人 + 在目標旁的錘 + 碎裂特效
對：BODY → HANDLE → HEAD → ACTIVE END FACE → CONTACT → FRACTURE
```

### S7 取消真斧中間層

斧好畫（薄刃插入＝高辨識 primitive）。
先畫真斧再換錘 → 模型學會出斧，換頭時重解接觸，大面積 cheek 又勝出。

留下的理解（可想斧，不可畫斧）：

```
若是斧：絕不用側面橫推，只用鋒切開
輸出必須是錘：鋒的角色 = ACTIVE END FACE
斧的刃側 = 錘的 CHEEK → 永不主力
畫面永不畫斧
```

### S8 受力點／禁槍線／V5 人審式

```
唯一 C = ACTIVE END ∩ 受擊面
n_HB ≈ − n_TARGET ，只共 C
柄軸 ≠ D ，人軸 ≠ D ，人→球心 ≠ D
錘軸 ⊄「接觸點→球心」（約 45°／對角，不是穿心矛）
D = aX+bY+cZ ，禁止純 ±X 把全世界排成一支槍
```

V5 給人審，不整段餵模。

### S9 根問題：PROMPT 有 ≠ 圖 FOLLOW

```
PROMPT SPACE（D、C、法線）
↓
？ ← 缺可畫中介；模型用先驗填＝大塊金屬貼球
↓
IMAGE SPACE（輪廓／遮擋／接觸）
```

管線：

```
PHYSICS TRUTH → VISUAL PRIMITIVE COMPILER → GENERATOR → PIXEL AUDIT
FAIL：修編譯器，不堆真理公式
```

單張畫不出的東西（速度、力矩、T−1）只審不餵。

編譯例：

```
| 真值       | 可畫句                 |
| -------- | ------------------- |
| n_HB = D | 小平端面是唯一碰玻璃的金屬輪廓     |
| 禁 cheek  | 長側壁在側／後，不吻玻璃        |
| 非同軸      | 人＋柄＋球心不是一條螢幕直線；擊點偏心 |
| 裂從 C     | 裂只從錘碰到的點長出          |
```

### S10 可簡可繁 V6（餵模層）

生成器解的是：女人在左、手上有錘、右大球、金屬碰到玻璃、裂從那點開、柄是斜的。

```
CORE
woman_LEFT + HAMMER_IN_HANDS + TARGET_RIGHT
+ touch = striking_FACE ∩ shell
+ cracks_FROM(touch)
+ handle_ANGLED
+ body_NOT_on_gun_line
錘是 CONST，不是可選道具
```

保險句（加場景必帶）：

```
she is still holding the sledgehammer
the hammer is in the picture
do not replace the hammer with a hand touch
both hands on the handle
```

k=0 核 → 先衣再景 → 最後光／FX。diner／霓虹高危。一掉幾何就回到 k=0。

k=0 最短模板：

```
Single 16:9. Woman left, real hammer in both hands, huge glass sphere right.
Striking face touches the glass; cracks only there.
Handle angled — not a spear through the ball center.
Body not on one line with handle and ball center.
No axe. No text.
```

### S11 實驗支線（找 primitive，不成片）

雙刃斧橫斬浪／冰波 → 棒橫斬冰球 → 再回到錘。
正式成片禁止出斧。

### S12 結構解：厚十字／正交／plus-sign

十字夠用；要**加厚**，不要拉長垂直臂。
禁止連續 Img2Img。
錯路：4 把錘、4 把獨立錘、2D 平面十字、一柄四頭、教學圖畫成單頭 T。

**正交厚十字（曾用公公式）：**

```
a massive extremely thick cross-shaped war hammer,
the hammer head features a robust orthogonal design
with both prominent vertical and horizontal thick solid striking blocks,
featuring heavy flat striking faces on all top, bottom, left, and right ends
```

為什麼這樣寫：`orthogonal` 逼垂直相交；`vertical and horizontal` 逼兩臂都在；`top, bottom, left, and right` 逼四端都有面。

實測：厚與四向出來了，模型仍常畫成「厚重多面戰錘」，不是乾淨 plus-sign（+）。

**更乾淨 plus-sign 句（補強）：**

```
a massive thick plus-sign cross-shaped war hammer,
the hammer head is a clean orthogonal plus-sign formed by
one thick vertical solid rectangular bar and
one thick horizontal solid rectangular bar crossing at the center,
four equally thick solid rectangular striking blocks pointing
top bottom left and right, each end has a heavy flat striking face
the hammer must look like a thick metal plus-sign cross
not T-shape not X-shape not single head
```

Negative：`T-shape, single head, X-shape, thin arms, missing vertical arm, missing horizontal arm, thin hammer`

### S13 多向槌面合成圓頭（現用武器結構）

「由槌頭組成的圓」曾被畫成：女主站在槌頭圓環裡，或場景裡一顆錘星球。錯。

正確：

```
一把錘 + 一條柄 + 一個頭
頭上密鋪多個扁平槌面，面朝四面八方
所以頭看起來是圓
圓是結果，不是佈景
打玻球時，朝目標的那一面先觸
```

```
| 是          | 不是          |
| ---------- | ----------- |
| 仍是錘        | 晨星／鏈錘／刺釘狼牙  |
| 一柄一頭       | 很多把錘圍成圈     |
| 面是扁平打擊面    | 只為了圓而變成刺球   |
| 怎麼揮都有一面能對上 | 2D 加號只在一個平面 |
```

殘餘風險：模型愛畫「立方凸塊密鋪」（偏釘頭棒）。若要更像真正大錘端面，強調 `wide flat sledge faces`，禁 `spikes, studs, mace flanges`。

| 公式             | 在修的問題              |
| -------------- | ------------------ |

後一層不廢前一層。故事一直有效。

## 0. 進程方向（一條線）

```
原故事隱喻
→ 可拍之物（泡泡／爪機／奶昔／碎玻璃／天台）

→ 影像契約 16:9／光暈／顆粒／宏大／角色弧

### S6 剛體課（此後力學只當審核）

```
FACE ●────────────● FACE ← END STRIKING FACE
│ HEAD │
│ CHEEK │ ← 長側壁，禁止領先
└────┬─────┘
│ HANDLE（中眼，⊥ 頭長軸）
```

- 打的是端部 FACE，不是 cheek、不是柄
- 「小面」＝端部平面，不是把錘臉縮成針
- END FACE 是揮動的終端幾何，不是另貼上去的臉
- 裂必須從接觸中心長；目標在接觸前應仍完整

失敗碼：CHEEK-FIRST／SIDEWAYS／STATIC-END-FACE／HANDLE-FIRST／PRE-FRACTURE／CONTACT RE-SOLVE／AREA BIAS。

A（有力但 cheek 先到）與 B（端面對但像按住）是同一錯：把「人的姿勢」和「錘的接觸」當兩個物件。

```
錯：有力的人 + 在目標旁的錘 + 碎裂特效
對：BODY → HANDLE → HEAD → ACTIVE END FACE → CONTACT → FRACTURE
```

### S7 取消真斧中間層

斧好畫（薄刃插入＝高辨識 primitive）。
先畫真斧再換錘 → 模型學會出斧，換頭時重解接觸，大面積 cheek 又勝出。

留下的理解（可想斧，不可畫斧）：

```
若是斧：絕不用側面橫推，只用鋒切開
輸出必須是錘：鋒的角色 = ACTIVE END FACE
斧的刃側 = 錘的 CHEEK → 永不主力
畫面永不畫斧
```

### S12 結構解：厚十字／正交／plus-sign

十字夠用；要**加厚**，不要拉長垂直臂。
禁止連續 Img2Img。
錯路：4 把錘、4 把獨立錘、2D 平面十字、一柄四頭、教學圖畫成單頭 T。

**正交厚十字（曾用公公式）：**

```
a massive extremely thick cross-shaped war hammer,
the hammer head features a robust orthogonal design
with both prominent vertical and horizontal thick solid striking blocks,
featuring heavy flat striking faces on all top, bottom, left, and right ends
```

為什麼這樣寫：`orthogonal` 逼垂直相交；`vertical and horizontal` 逼兩臂都在；`top, bottom, left, and right` 逼四端都有面。

實測：厚與四向出來了，模型仍常畫成「厚重多面戰錘」，不是乾淨 plus-sign（+）。

**更乾淨 plus-sign 句（補強）：**

```
a massive thick plus-sign cross-shaped war hammer,
the hammer head is a clean orthogonal plus-sign formed by
one thick vertical solid rectangular bar and
one thick horizontal solid rectangular bar crossing at the center,
four equally thick solid rectangular striking blocks pointing
top bottom left and right, each end has a heavy flat striking face
the hammer must look like a thick metal plus-sign cross
not T-shape not X-shape not single head
```

Negative：`T-shape, single head, X-shape, thin arms, missing vertical arm, missing horizontal arm, thin hammer`

### S13 多向槌面合成圓頭（現用武器結構）

「由槌頭組成的圓」曾被畫成：女主站在槌頭圓環裡，或場景裡一顆錘星球。錯。

一把錘 + 一條柄 + 一個頭

所以頭看起來是圓
圓是結果，不是佈景
打玻球時，朝目標的那一面先觸
```
